# 0.1.15 共振部件参考修正

最后范围来自用户连续的更正：撤回分频重绘；共振Ⅰ保留 0.1.14 原刃面，在尖端补同材质红色并补完整上沿弧线；核对共振Ⅱ与给定图片的差异。

主代理绘制源为 `correct_reference_pixels.py` 及 `root-pixel-states.json`。最终 JSON SHA-256：`075900A804387B31A3E87EAF1FB3ACDEC4B21D1F83C5A6B1247707781FBD1B36`。最终预览为 `artwork/validation/root-tier-polish-v0.1.15/reference-final-fx/`。

- 共振Ⅰ只更改 87 个像素，用原 0.1.14 的共振Ⅱ材质补尖端和深红分界上沿的连续弧线。原刃面、高光、其余原发光点保留。
- 共振Ⅱ此前把参考红刃整体平移了 `(5,-1)`；红色材料多数并非另画，但它和镐身的相对位置已改变。此版使用原 native128 参考坐标，保留完整轮廓、深红分界、两层红刃与高光；连接处用参考图的幽匿材质接续，保护其他强化部件的普通区域。该部件相对 0.1.14 更改 975 个像素。
- 新连接处的青色亮点有 3% 轻微明暗变化，红刃仍沿用原强度和 16 帧、每帧 3 tick 的节奏。发光不改透明度、不出现黑暗帧。
- 分频Ⅰ/Ⅱ/Ⅲ、调谐、延展Ⅰ/Ⅱ/Ⅲ、普通状态的 RGBA 与 FX 数组完整保持 0.1.14。所有状态仍是单个连续物体。

主代理已审阅共振的暗底和白底 6 倍近景与全阶段图，发现并修复旧平移删除区域导致的镐头连接空洞。最终共振Ⅱ所列参考轮廓坐标的 RGBA 与 native128 参考一致，见 `polish-audit.json`。这并不代表整把全强化工具与 1254 像素参考图片逐像素相同：项目沿用普通镐共同镐身，其他部件位置沿用 0.1.14，native128 的全图仍有 3028 个不同像素。不可把部件核验表述为全图完全相同。

未采用的分频切面重绘与较早的断开连接草稿均只保留为历史，不接入游戏。用户否定记录见 `artwork/validation/root-tier-polish-v0.1.15/REJECTED-DRAFTS.md`。
