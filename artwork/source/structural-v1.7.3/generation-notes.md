# 1.7.3 — 强化延展之晶二阶（已部署并冻结）

Only `enhanced_extension_crystal_2` is redesigned. The target uses the new source in `design_prompt.md`; the original generated image is preserved at `enhanced_extension_crystal_2-imagegen.png`. The local reference board and the previous 1.7.2 target model/base/glow/meta snapshot are retained in this source/validation tree. The other eleven item assets, including the basic extension pupil-motion texture, were left byte-for-byte unchanged.

Import procedure is mechanical and fully reproducible by `artwork/generate_extension_tier3_v1_7_3.py`: convert raw RGBA alpha to a >=128 binary mask to find the tight object bounds, crop that bbox (507x780 at generation), nearest-neighbor resize to 18x28 while preserving its aspect, and center at x=7,y=2 on a transparent 32x32 canvas. Set final alpha to 255 only where resized alpha>=128 and 0 elsewhere. RGB is never hand-drawn or recolored. The final source has 276 opaque pixels, bbox (7,2)-(24,29), at least two transparent rows vertically and seven transparent columns on each side. `old-new-16-32.png` shows the original 1.7.2 asset, the new 32px import, and a true 16x16 nearest-neighbor downsample enlarged for inspection.

The model is rebuilt for the new silhouette: no parent, `gui_light=front`, target display transforms copied exactly from the 1.7.2 target snapshot. One box per opaque pixel uses `from=[x/2,16-(y+1)/2,7.5]`, `to=[(x+1)/2,16-y/2,8.5]`, and center UV `[x/2+.25,y/2+.25]`. Every pixel has north/south faces; only eight selected green-ring pixels bind glow, and only silhouette-boundary side faces are present, all using layer0. Eight glow-mask pixels (2.90% of the sprite's opaque pixels) retain source RGB in quiet states. The small two-pixel moving reflection uses source same-hue RGB raised by at most 12% for one pixel and 4% for its adjacent companion; no glow pixel is darkened. Animation is 16 frames x 6 ticks = 4.8 seconds, no interpolation, fixed binary alpha 0/255, north/south paired Forge block/sky light 15 and AO false.

The root reviewed and approved the candidate, which is deployed and frozen under `src/main/resources/assets/echopickaxe/`; the independent `audit_target_independent.py` passes both candidate and production. It confirms 276 correctly mapped pixel boxes, eight paired glow cells, fixed alpha, no dim frame, exact retained display transforms, and 44 other item model/texture files byte-identical to the 1.7.2 release. Deployed SHA-256 values for the four target files are recorded in `deployed-sha256.json`. Candidate files and the full-cycle gray-background GIF remain in `artwork/validation/v1.7.3/` for review.
