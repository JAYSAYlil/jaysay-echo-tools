# Emissive assets 1.6.0

The built-in image generation call produced `design_reference.png` as a unified visual reference only. It was not used as a game texture and did not replace or edit any existing item art. The exact prompt, reference-sheet path, and returned image path are recorded in `design_prompt.md`.

All production pixels are generated deterministically from the original 32×32 RGBA item textures. `artwork/generate_emissive_v1_6_0.py` selects hue-family coordinates inside the existing opaque silhouette, retains those exact coordinates as a fixed alpha mask, and animates RGB with per-item color palettes and motion waves. The emission RGB is computed from a 12%–40% blend toward the family target and a 0.50–1.05 brightness multiplier over the wave, preserving the original palette at troughs and avoiding white washout at peaks. Animation uses 16 frames. Four-frame-arm tuning animation offsets each arm by one quarter of the cycle, creating a full scan per 4.8-second cycle.

Each `<item>_glow.png` is a 32×512 strip with 16 vertically stacked 32×32 frames. Every frame shares the same binary alpha mask (`0` or `255`). The adjacent `.png.mcmeta` uses matching `width`/`height` 32, the item's `frametime` in `manifest.json`, sequential frame indices, and `interpolate: true`.

For each existing model, the generator rebuilds from `base_models/<item>.json` (captured before the first emissive generation). Existing elements and display transforms remain intact. Only the `north` and `south` faces at selected opaque sprite coordinates bind `#glow`; these faces set Forge `block_light: 15`, `sky_light: 15`, and `ambient_occlusion: false`. Other faces stay on `#layer0`. The original base texture copies are retained in `base_textures/` and verified byte-for-byte against current base textures after generation.

Validation output is in `artwork/validation/v1.6.0/`: `masks.png`, `low-peak.png`, and `emissive-items-preview.gif`, plus one mask PNG per item. The GIF samples the animation at one Minecraft tick and blends adjacent RGB frames to mirror `interpolate: true`; the low/peak sheet places all 12 originals at each item's darkest and brightest generated frames side by side. `manifest.json` records per-item coordinates, palette groups, coverage, face counts, frame timing, interpolation, motion, and cycle duration.
