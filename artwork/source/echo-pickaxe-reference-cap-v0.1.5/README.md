# 0.1.5 same-source resonance-cap recolor

Status: preview only, awaiting user feedback. No resource candidate is generated.

`recolor_reference_cap.py` uses the approved normalized64 resonance tiers as the exact cap coordinate and alpha source. It overlays those pixels on the approved common64 body and maps cap luminance to the neighboring common64 head palette. It also makes the res0 v031 preview by replacing only those same cap pixels in the pinned 0.1.4 baseline image. The earlier hand-drawn hook draft is rejected and is retained only as a comparison image.

The four-state design comparison, three-state family comparison, and new-cap closeup are written to `artwork/validation/v0.1.5/cap-reference-draft/`. The script does not write candidate resource trees or production files.
