# 各级强化局部完善

本批次保留现有普通回响镐与最高级强化造型。主代理直接确定局部像素与发光点；Luna 仅实现逐像素处理、资源接入和验证代码。此前新画的整镐概念稿排除使用。

- 共振Ⅰ：接顺弧形刃口的晶面反光，不借用Ⅱ的隆起背脊。Ⅱ保持原有双层刃形与尖端。
- 分频Ⅰ、Ⅱ：在原外侧刃口范围补足连续紫色晶面，修正暗色断续细条。Ⅰ保持单片主晶刃，Ⅱ保留第二片晶面，Ⅲ保留完整末段晶刃。
- 延展Ⅰ：使用小型翠绿晶质眼座，保留瞳孔与虹膜。Ⅱ使用完整的两侧青色护托，Ⅲ保留上方第三护臂。Ⅰ不复制高等级的青色护臂。
- 调谐Ⅰ：保持已认可的四角星芒，保留清晰的中央核心。

动态效果按 `root-animation-spec.json` 的精确坐标与参数执行：新增紫刃亮边幅度Ⅰ为 3.5%、Ⅱ为 4.5%；翠绿眼座为 2.5%。其他已存在部件沿用原有分组动态，中心星芒与黑色眼瞳保持稳定。全程固定透明度，16 帧、每帧 3 tick。

静态审阅：主代理查看了 preview-v2 的深色、白色部件对照及整镐对照。低、中等级实际修改保留在独立副本；普通镐与满级部件保持原字节。技术通过不能代替视觉审阅，本记录不声称用户已认可新增像素。
