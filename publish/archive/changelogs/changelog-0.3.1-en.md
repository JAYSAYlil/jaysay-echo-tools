## 0.3.1 — first public release

**Packaging**

- Added project metadata: author credit, project and issue-tracker links, in-game icon, and a proper licence file (all rights reserved; Forge MDK files keep their own licence).

**Included gameplay (0.3.0)**

- The Echo Upgrade Smithing Template now also drops from the **Warden**: 10% when a player kills it, +1 percentage point per Looting level (11% / 12% / 13%). Non-player kills never drop it, and the Warden keeps its vanilla sculk catalyst and XP drops. Ancient city chests still hold the template at 5%.
- Bonus echo shards from sculk blocks now scale with the pickaxe's **Fortune** enchantment: 10% / 15% / 20% / 25% for Fortune 0/I/II/III. A hoe in your main hand with an upgraded pickaxe in your offhand still works, and always reads the pickaxe's Fortune — the hoe's own Fortune never applies and the two never stack.

No new items, no NBT or network changes. Existing worlds and pickaxes are unaffected.
